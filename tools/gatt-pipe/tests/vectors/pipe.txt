# The cases both implementations of the pipe have to agree on.
#
# `tools/gatt-pipe` (Rust, the reference) and `calypso-app/lib/gatt/pipe.dart`
# (Dart, the app) run every line here through their own state machines and
# compare the outcome. One file rather than two suites, because two suites is how
# two implementations of one protocol drift apart quietly: the interesting
# failure modes are the ones neither side can produce on demand.
#
# Format, `|`-separated, no spaces:
#
#   name | bytes | mtu | max_message | drop | corrupt | duplicate | swallow_acks | timeout_ms | delivered | chunks
#
# bytes        the message length; the bytes themselves are `i % 251`, so both
#              sides build the same message from the length alone
# mtu          the ATT MTU the link negotiated
# max_message  the reassembly buffer, which is the promise a START makes
# drop/corrupt/duplicate
#              the nth data chunk from 1 to lose, corrupt a payload byte of, or
#              deliver twice; 0 for none
# swallow_acks 1 to lose every acknowledgement, which is what the timeout and the
#              retry limit are for
# timeout_ms   no-progress timeout the caller applies
# delivered    1 if the message arrives whole and equal, 0 if the transfer gives up
# chunks       data chunks the sender put on the wire in total, retries included
