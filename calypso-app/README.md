# calypso-app

The client side: syncs reps from the device over BLE, lists rep summaries, and
plots a single rep in 3D.

**Status: planning.** No code yet. Framework choice has narrowed to **Flutter**
(recommended) vs **React Native** — see the comparison in the plan.

See [`docs/app/README.md`](../docs/app/README.md) for: how iOS apps are usually
written, whether this can be a website (it can, except for Bluetooth), the
Flutter-vs-RN comparison and recommendation, the planned layout, the fixture
format that makes the client testable without hardware, features, testing
strategy, milestones and open questions.

Planned layout along the recommended (Flutter) path:

- `lib/protocol/` — decode `RepRecord` / `SyncMessage` (generated from `proto/`)
- `lib/transport/` — `RepTransport` implementations: fixture, BLE, recording
- `lib/plot/` — plot model (pure Dart) + `CustomPainter`-based 3D view
- `lib/ui/` — rep list, rep detail, timeline scrubber
- `test/` — unit, widget and golden-file tests
- `assets/fixtures/` — checked-in `.pblog` logs, generated by the firmware's own
  protobuf encoders
