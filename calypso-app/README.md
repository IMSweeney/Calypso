# calypso-app

The client side: syncs reps from the device over BLE, lists rep summaries, and
plots a single rep in 3D.

**Status: planning.** No code yet — the platform decision is between a website
wrapped for iOS (Capacitor) and a native SwiftUI app. See the plan.

See [`docs/app/README.md`](../docs/app/README.md) for: how iOS apps are usually
written, whether this can be a website (it can, except for Bluetooth), the
recommendation (website first, wrap it later), the planned layout, the fixture
format that makes the client testable without hardware, features, testing
strategy, milestones and open questions.

Planned layout along the recommended path:

- `web/` — the UI: three.js 3D plot, rep list, timeline scrubber, transport
  implementations (fixture + BLE)
- `ios/` — Capacitor shell + Xcode project
- `fixtures/` — checked-in sample logs (`.pblog`), generated by the firmware's
  own encoders
